# Cardápio digital · Black Balloon Music Club

Cardápio online da Black Balloon Music Club (Botucatu-SP), no mesmo visual do cardápio impresso 2027.

**Acesse:** https://fabiovinicius0-design.github.io/cardapio-black-balloon/

- **Lado A:** drinks especiais e combos.
- **Lado B:** carta de bebidas (cervejas, uísques, destilados, cachaças, drinks prontos, licores e aperitivos, espumante e sem álcool).
- Cardápio só para visualização: os pedidos são feitos no bar.

## QR Code

`qr.png` e `qr.svg` apontam para o endereço acima. Use para mesas, displays e materiais impressos.

## Atualizar preços

Os preços ficam em `index.html`. Ao alterar e salvar no GitHub, o site se atualiza sozinho em cerca de 1 minuto. O QR Code continua o mesmo.
